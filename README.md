# Test Automation Project – IT23396036

##  Project Overview
This project automates the testing of a system that converts chat-style Singlish inputs into Sinhala using Playwright.

The main objective is to identify and validate 50 negative test cases where the system fails to correctly convert Singlish text into Sinhala. These test cases include phonetic spelling, abbreviations, mixed language usage, and typing errors.

##  Tools & Technologies Used
- Playwright (Test Automation Framework)
- JavaScript / Node.js
- Git & GitHub
- Excel (Test Case Management)
