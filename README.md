# TPM Assignment 1 - Option 1 Test Automation (IT23396036)

##  Project Overview
This project automates the testing of a system that converts chat-style Singlish inputs into Sinhala using Python automation.

The main objective is to execute **50 test cases** and validate the system’s accuracy in Singlish to Sinhala conversion. The results are automatically recorded in an Excel file.

---

##  Prerequisites
- Python 3.11 or higher installed
- Internet connection for package installation
